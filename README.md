# Práctica 03 — Formularios, Validación, Listas y Diseño Responsivo

## Objetivo

Construir un formulario de registro de productos utilizando Flutter,
implementando validaciones, manejo de eventos, visualización de registros
mediante una lista y diseño responsivo.

## Descripción

La aplicación permite registrar productos indicando:

- Nombre
- Categoría
- Precio
- Existencia

Los productos registrados se muestran en una lista. También es posible
eliminarlos y consultar el valor total del inventario.

## Funcionalidades

- Registro de productos.
- Validación de campos.
- Selección de categoría.
- Visualización mediante ListView.
- Eliminación de productos.
- Cálculo del valor total del inventario.
- Diseño responsivo.
- Pruebas con Flutter.

## Requisitos

- Flutter
- Dart
- Visual Studio Code
- Git
- GitHub
